# Single-Cell and Pseudobulk Transcriptomic Analysis

This directory contains workflows used for processing, integrating, and analyzing single-nucleus RNA-seq datasets used in this study.

Analyses included:

- Custom Mbp-Golli / Mbp-Classic reference generation
- Cell Ranger alignment
- CellBender ambient RNA correction
- Scrublet doublet filtering
- Harmony integration
- Seurat clustering
- Pseudobulk differential expression analysis
- Cell-type enrichment analysis

---

## Overview

Publicly available and newly generated single-nucleus RNA-seq datasets were processed jointly to investigate cell-type-specific transcriptional changes associated with peripheral nerve injury and neurodegeneration.

To enable isoform-aware Mbp quantification, a custom Cell Ranger reference was generated in which canonical Mbp transcript annotations were modified to distinguish:

- Mbp-Golli
- Mbp-Classic

transcript models.

---

## Workflow Summary

### 1. Custom Reference Generation

```text
Creating_new_reference_for_Golli_Compact_Mbp.sh
run_cellranger_mkref.sh
```

These scripts generate a modified Cell Ranger reference genome containing separate Mbp-Golli and Mbp-Classic transcript annotations.

Reference generation was performed using:

- Cell Ranger v9.0.1
- GRCm39 genome
- Modified GTF annotation

---

### 2. Cell Ranger Alignment

```text
run_cellranger_count.sh
```

Single-nucleus RNA-seq FASTQ files were aligned using Cell Ranger.

Processing included:

- alignment
- barcode correction
- UMI counting
- intronic read inclusion

---

### 3. Ambient RNA Removal

```text
run_cellbender.sh
```

Ambient RNA contamination was removed using:

- CellBender v3.1

---

### 4. Integration and Downstream Analysis

```text
Integration_and_Pseudobulk_DESeq2.R
```

This workflow performs:

- Seurat preprocessing
- quality control filtering
- Scrublet doublet removal
- Harmony integration
- clustering and annotation
- pseudobulk aggregation
- DESeq2 differential expression
- Propeller cell proportion analysis
- Fisher’s exact enrichment testing

---

## Quality Control

Cells/nuclei were filtered using the following thresholds:

| Metric | Threshold |
|---|---|
| Detected genes (nFeature) | >500 and <8000 |
| Total counts (nCount) | ≥10 |
| Mitochondrial percentage | <15% |

Doublets were identified using:

- Scrublet v0.2.3

---

## Integration

Datasets were normalized and integrated using:

- Seurat v5.2.1
- Harmony v1.2.3

Integration was performed across:

- biological replicates
- experimental conditions
- nerve types

---

## Pseudobulk Differential Expression

Pseudobulk expression profiles were generated by summing counts across:

- cell type
- biological replicate

Differential expression analysis was performed using:

- DESeq2 v1.44.0

Genes were considered significantly differentially expressed using:

| Parameter | Threshold |
|---|---|
| Adjusted p-value | ≤ 0.05 |
| Absolute log2 fold change | ≥ 1 |

---

## Cell-Type Enrichment Analysis

Enrichment of multi-DET genes within cell-type pseudobulk DEGs was evaluated using:

- one-sided Fisher’s exact test
- Benjamini–Hochberg multiple testing correction

Results were summarized using:

- odds ratio
- FDR-adjusted p-value
